I am a SQL Server DBA in Vancouver, WA, and the founder of Detent Point, a one-person
company that builds PowerShell and SQL Server tools: SqlCertForge for certificate work,
ClusterValidator for failover clusters, GitEasy for Git in plain English, and DetentShell,
an ISE-style IDE for PowerShell 7.

I wrote the 25-part [Pester for Beginners](https://keith-ramsey.com/) series, and I keep a
[comparison of PowerShell editors](https://detentpoint.com/best-powershell-ide/) that says
where each one wins.
